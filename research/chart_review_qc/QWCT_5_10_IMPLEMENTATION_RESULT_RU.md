Пример ошибки до исправления: `contaminated=True`, `accumulation=None` давали g12=True и +1.5 в bounce score; теперь g12=None, прибавки нет. Численные параметры 10 реакций, выбор модели, BPU1/BPU2, строгий SEC cutoff и Risk Gate сохранены.

## Что делает единый запуск

1. Берёт реальные native RAW D1, вычисляет **нативные** Wilder ATR14 и SMA50; фиксирует уровни и решение до 09:30. Текущий дневной бар не используется.
2. Показывает **все 14** признаков с деталями, включая незавершённые M5-staircase / market-context подпункты. Если сценарий не принят, отдельный premarket probe помечен `PREMARKET_PROBE_ONLY`; он не становится принятой моделью.
3. Запрашивает только M1 четырёх заранее выбранных акций за одну сессию. Native TradeBarConsolidator строит M5 исключительно из наблюдаемых минут; для допустимого M5 нужны все пять. Дубли/плохая хронология блокируют; пропуски не заполняются.
4. Применяет существующие 10 M5-тегов к цене, замороженной утром. Направление определяется исходной ролью уровня, а не направлением breakout-входа. Равная цене закрытия линия имеет UNKNOWN role, не вымышленный support/resistance.
5. Считает strict-limit FIXED/FLOATING отдельно от остальных видов BSU. Off-grid cluster не округляется ради подтверждения; положительный статус не означает наблюдение реального лимитного игрока.
6. Для принятого D1 bounce использует существующий BSU bridge и BsuDetector. Только если действительно найден BPU1, допускает максимум **два** коротких SECOND History запроса на акцию с прежними strict cutoff/gap правилами. Никаких повторных тестов AAPL/PPHL ради повышения результата.
7. Для принятых решений вызывает канонический `build_intent` и показывает все восемь фильтров по каждому M5; сводные числа — проверки баров, **не сделки**. Один пример выбран для удобства чтения отчёта, не для отбора доходной сделки.

Historical SEC sample не создаёт `BpuTvxEvidence` вместо реального OnData. Поэтому даже хороший исторический sample не поднимает native bounce gate и не доказывает своевременную доступность. `risk_approved` не повышается, итог всегда `can_trade=false` / `NOT_TVX_PASS`. Состав Top10, author BSU и out-of-sample accuracy этим фиксированным набором не проверяются. Версия локальных config/levels в Cloud не сертифицируется агентом; ошибка импорта/различия конфигурации не являются data PASS.
