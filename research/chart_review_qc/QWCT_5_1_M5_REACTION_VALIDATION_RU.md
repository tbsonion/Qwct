# QWCT 5.1 — независимый механический аудит реакций M5

**Статус:** скрипт и тесты подготовлены; конкретный Native QuantConnect запуск версии 5.1 ещё требуется. Без сделок.

## Исходное наблюдение (QWCT 5.0, НЕ результат 5.1)

QWCT 5.0 на native RAW SRPT за 2024-06-03: **389/390 M1, 77/78 M5**, пропуск окончания 13:10 ET, GAP_RESETS=1. На заранее замороженном $125 (D1 mirror software proxy): 19 тегов семи видов, включая WICK_RECLAIM + FALSE_BREAK_2BAR в 10:30, MIRROR_RETEST в 11:30 и 11 скользящих окон CONSOLIDATION. Метки — не авторская разметка Герчика. Реакции не являются BSU/BPU1/BPU2, TVX и торговым сигналом.

## Как работает QWCT 5.1

[Одна новая ячейка](QWCT_5_1_SRPT_M5_REACTION_VISUAL_AUDIT_ONE_CELL.py) для существующего Qwct-M5-Cohort-Research/research.ipynb. Никаких замен main.py или strategy/*.py.

1. Исторические native RAW D1 и допущенный до сессии D1 уровень, настоящие M1 и native TradeBarConsolidator M5. Не заполняем 13:08 синтетической ценой.
2. Native Wilder M5 ATR14, закрытые M5, source end/anchor end и программные теги без будущих свечей.
3. Независимый аудитор заново проверяет OHLC, точный anchor, непрерывность, сторону и отражённые в QWCT 5.0 эвристики для всех десяти реакций. Аудитор НЕ вызывает детектор для подтверждения результата и не подменяет авторскую оценку.
4. Проверяется весь набор тегов CHECKED/PASS/FAIL. Три заранее выбранных графика: 10:30 ложный пробой/возврат, 11:30 зеркальный ретест, 10:40–11:10 проторговка/пила. Любая несовместимость даёт fail-closed без подтверждения.

## Что ещё нельзя заявлять

- Механический PASS означает согласованность с текущими программными формулами, а НЕ правильность по Герчику.
- Порог хвоста 0.40, ATR/окна и определение BREAK_FOLLOWTHROUGH — эвристики QWCT, не доказанные авторские параметры.
- CONSOLIDATION 11 — это перекрывающиеся окна, а не одиннадцать независимых сделок.
- Чтобы независимо измерить точность, нужны авторские размеченные примеры с временем, стороной и ценой уровня. Текущий статус: GERCHIK_GROUND_TRUTH_LABELS=0.

## Критерий

После native Cloud запуска необходимы строки QWCT 5.1 AUDIT SUMMARY с FAIL=0, QWCT 5.1 COMPLETE и три визуальных фрагмента. Нельзя подкручивать пороги ради нулевых ошибок; любое несовпадение сначала исследуется.
