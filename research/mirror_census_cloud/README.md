## Exact implementation

New separate [`main.py`](./main.py) makes an **independent study**. It intentionally leaves [2.8 native original / M5 study](../cohort_cloud/main.py), all production strategies, `strategy/levels.py`, `strategy/patterns_bsu.py`, original tick equality, margin/broker code and original parameters **unchanged**.

- LEAN Fundamental selector and **original selected symbol membership**: `strategy.select_liquid_fundamentals` (same import and 50-stock daily liquidity sort as prior native 2.8). The same existing **`strategy/timing_gate.py`** validates previous observed historical Fundamental callback via LEAN `Exchange.Hours.get_next_market_open` only when no same-day callback was supplied before 09:29 ET. Empty same-day memberships are never replaced by yesterday's selection. All market sessions use official LEAN schedule, not homemade holiday dates. Expected observed baseline when a successful June run finishes: 19 scans, 14 strict same-day, 5 verified next-session selections, 950 stock-days.
- **All 50** member symbols on each approved session get the same **180 original, closed, RAW D1 TradeBar history** request, **Wilder ATR14, SMA50 and volume SMA20 native LEAN indicators**, and as-of D1 `levels_for_session` constructed by the existing source module. The entire D1 source (not an M5 retrospective) is known before 09:29.
- Count *ALL* `kind='mirror'` and `source='swing_cluster'` D1 levels **BEFORE any Stage2 filtering or top-ten Shadow limit**. Different units are clearly labeled: `stock_days` counts selected symbols across days, `mirror_stock_days` counts D1 frames with one or more mirror levels, `mirrors` counts **level × stock-day records**; one symbol can have multiple mirrors. **Not trade counts.**
- A read-only **independent copy** of previously reviewed [`audit_mirror`](../chart_review_qc/mirror_asof_audit.py) checks original support/resistance provenance without lookahead, right-hand swing confirmation, separate price-close-through breach, later retest on the reversed side, and causal mirror `valid_from`. Unknown origin side and source chronology fail closed. Mirrors are **automated D1 proxies**, not manually certified Gerchik levels.
- A pure `mirror_gates` evaluates exactly the **existing original gate values**: Stage2 `passes_gerchik_screener`, `cfg.min_touches`, `cfg.min_level_strength`, `cfg.level_proximity_atr=1.0`, matching local and global native-SMA trends, and correct new *reversed* role: original support→resistance for short, original resistance→support for long. The selected side is frozen using previous D1 close, the same way the original cohort chooses it; **no widened BPU1 tolerance, no relaxing the 1.0 ATR rule**.
- Report marginal gates **separately from a cumulative funnel**, so `near` across *all* proxies is not misread as eligible among Stage2-qualified proxies. `eligible_proxies` and `QWCT MIRROR READY` mean only **morning D1 conditions**; no M5 pattern, `BpuDetector`, -30 seconds TVX, source pivot tick/basis, or 8 complete model gates. Counts before this final manual/market verification **cannot be called trades**.
- Outputs are `QWCT 3.0 MIRROR CENSUS ACTIVE`, `QWCT MIRROR TIMING VERIFIED`, `QWCT MIRROR DAY`, `QWCT MIRROR SUMMARY`, `QWCT MIRROR GATES`, `QWCT MIRROR REJECTS`, up to 40 illustrative `QWCT MIRROR NEAR`, first 50 `QWCT MIRROR READY`, and `QWCT MIRROR OUTPUT`. **The complete summary, not truncated examples, is authoritative for counts**.
- Same one-month maximum `(end-start).days <=35`; explicit `timing_mode=next_session|strict`. The new [`tests/test_mirror_census_research.py`](../../tests/test_mirror_census_research.py) tests gating direction, original 1.0 ATR threshold, chronology, no-lookahead PIT imports, absence of orders/mock M5 and untouched source baseline. ## Source / risk guardrails

- `mirror` is a **reversed-role software cluster**; `PROXY_VERIFIED` means source date/breach/retest are internally consistent. It is **not** a universally valid Gerchik BSU.
- A historical first swing `first_idx` vs D1 cluster median can be separated by tens of native ticks; mirror source price/tick grid and RAW/SCALED_RAW are NOT independently certified by this initial census and must be audited **if** a positive eligible proxy actually exists.
- Limits of this study: 19 trading sessions in June 2024 of one particular liquidity-capped PIT universe; does not establish long-run expected returns or quantify all alternative discretionary levels.
